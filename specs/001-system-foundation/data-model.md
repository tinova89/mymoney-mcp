# Data Model: System Foundation

## Account (`accounts`)

Root of all financial data (Constitution II). No create/read operations in this feature
(spec FR-008); rows exist only as test data.

| Field | Type (PostgreSQL) | Rules |
|---|---|---|
| `Id` | `uuid` PK | Generated by the app. |
| `DisplayName` | `varchar(100)` | Required, trimmed, not blank. |
| `Group` | `varchar(100)` | Required, trimmed, not blank. Exact, case-sensitive match. |
| `CreatedAt` | `timestamptz` | Set on insert (UTC). |

- Index: `ix_accounts_group` on `Group`.
- Query filter `"AccountGroup"`: `Group == IAccountGroupContext.Group` (research R5).
- No soft-delete columns yet: no delete operation exists (YAGNI, Constitution VIII). The first
  feature that deletes accounts adds them with a `"SoftDelete"` named filter.

## RefreshToken (`refresh_tokens`)

Supports token rotation (research R7). Not account-owned: authentication happens before any group
is known, so it has **no** group filter.

| Field | Type | Rules |
|---|---|---|
| `Id` | `uuid` PK | |
| `ClientId` | `varchar(100)` | Required. |
| `TokenHash` | `varchar(64)` | SHA-256 hex of the opaque token. Unique index. |
| `ExpiresAt` | `timestamptz` | Required. |
| `CreatedAt` | `timestamptz` | Required. |
| `RevokedAt` | `timestamptz` null | Set when used or revoked. |

- Valid when `RevokedAt is null and ExpiresAt > now`.
- Using a token sets `RevokedAt` and creates a new row in the same database transaction.

## Account group (value, not a table)

- Comes only from the `X-Account-Group` header, trimmed. Never from the token or the body.
- Missing or blank → `400` (contracts/http-conventions.md).
